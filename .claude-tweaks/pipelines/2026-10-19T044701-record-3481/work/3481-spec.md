# 3481: matchPreExisting adjudicates a run as covered while failures no named file accounts for remain

Origin: ledger resolve gate (from #3204 wrap-up)

Defer-reason: pre-existing-outside-diff

## Current State

`matchPreExisting` (`plugin/bin/lib/verify/pre-existing.js`, #3129) returns `eligible: true` when every failing file the log names matches the declared `preExisting` allowlist. Its caller (`plugin/bin/verify.js`, the `matchPreExisting({ failingFiles: allFailingFiles, ... })` call) builds that file list with `extractFailingFiles` and runs no unattributed-failure accounting for any family.

A failure the log carries but extraction cannot tie to a file is therefore invisible: the run can be adjudicated as fully covered by the allowlist while an unaccounted failure remains. #3066 closed the same gap for flaky retry (`unattributedFailureCount`) and #3204 extended that to the summary family; `pre-existing.js` was outside both diffs. Raised in #3204's final whole-branch review.

## Deliverables

- [ ] In `plugin/bin/verify.js`, compute each non-skipped failing check's `unattributedFailureCount` and refuse the `preExisting` adjudication when any check reports a positive count (`unattributed-failures: {N}`) or `null` (`no-accounting-guard: {family}`), the same fail-closed posture flaky retry takes.

- [ ] Tests for a spec log and a TAP log with an unattributed failure, and for a summary-family log, each refused.

- [ ] Update the `preExisting` prose in `plugin/skills/test/verification.md` to name the new refusal reasons.

## Acceptance Criteria

- [ ] A spec or TAP run whose failing files are all covered by `preExisting` but whose log also carries an unattributed failure is not adjudicated as passing.

- [ ] A summary-family run is not adjudicated through `preExisting` and the refusal names `no-accounting-guard`.

- [ ] A fully attributed run covered by `preExisting` is still adjudicated as before.

## Release Note

Declared pre-existing test failures can no longer hide an additional failure the runner could not attribute to a test file.
