# 3661: dispatch's first-call artifact gate never reads verify.js --stamp-status, so a raw npm test first call leaves no stamp for call 2

Origin: #3284 wrap-up (run 2026-10-19T202749-record-3284), ledger item 1

Defer-reason: tangential

## Current State

A dispatched group's first call (`/flow {target} build,test`) can finish its test phase by running raw `npm test` instead of `/claude-tweaks:test`, and still report `build-test-ok`. That leaves no runner-written `verify.js` pass stamp, so the second call's review Step 1.5 reads `verify.js --stamp-status` as `present: false` and re-runs the full suite (the exact shape of #3034's ~117s re-run).

#3284 closed `/claude-tweaks:test`'s own stamp gaps (the Skip-if-recent Mismatch skip in `plugin/skills/test/verification.md`, the failed-checks-only re-run in `plugin/skills/test/fix-mode.md`). It did not touch the dispatch gate: `checkFirstCallArtifacts` in `plugin/bin/lib/dispatch/first-call-artifact-check.js` and `plugin/bin/verify-run-bookends.js` never read `--stamp-status`, and `plugin/skills/dispatch/task-prompt.md` (the CRITICAL self-check paragraph near line 176) still accepts a raw test-output log as call 1's self-check artifact.

## Deliverables

1. Add a stamp-at-HEAD read (`verifiedHead` from `verify.js --stamp-status`) to the first-call artifact gate, with a stated posture for an absent or stale stamp (block, repair by re-running through the runner, or note) chosen and documented.

2. Drop the raw test-output-log alternative from `task-prompt.md`'s first-call self-check so the artifact a first call must produce is the runner's stamp plus its `report.json`.

## Acceptance Criteria

A first call whose test phase bypassed the runner (no stamp matching HEAD) is detected at the two-call gate before call 2 dispatches, with the chosen posture applied and logged.

A first call that ran `/claude-tweaks:test` (stamp present, `verifiedHead: true`) passes the gate unchanged.

## Release Note

No user-visible change — internal dispatch-gate fix so a first call that skipped the stamping runner is caught before the second call re-runs the full suite.
